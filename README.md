# SmartSort

**Tidy up any cluttered folder in seconds — entirely on your Mac.**

SmartSort cleans up the folders where everything piles up — your Downloads, your Desktop, that one folder you keep meaning to deal with. Point it at a folder and it proposes a tidy structure in seconds. You review every change before anything moves, and you can undo the whole thing with one click.

Everything runs locally. SmartSort uses the on-device intelligence built into macOS to understand your files — no cloud, no account, no tracking. Your files never leave your device.

---

## Features

- **Smart organization** — sorts files into clear, sensible folders by type and content, not just by file extension.
- **On-device intelligence** — groups related files using the machine-learning frameworks built into macOS.
- **Duplicate detection** — finds exact duplicates byte-for-byte, and flags near-duplicate images and documents.
- **Preview before you commit** — see exactly where every file is going, folder by folder, before anything moves.
- **One-click undo** — restores everything to exactly where it was.
- **Fully offline** — nothing is uploaded, nothing is collected, and there is no sign-in.

## Requirements

- macOS 26 or later
- Smart categorization and similar-file detection use Apple Intelligence and need an Apple Intelligence–capable Mac. On other supported Macs, SmartSort still sorts deterministically.

## How to use

1. Open SmartSort and choose a folder to organize.
2. SmartSort scans the folder and proposes a plan — browse it folder by folder to see where each file will go.
3. Optionally enhance the plan with on-device intelligence, and review any duplicates SmartSort finds.
4. Apply the plan when you're ready. Changed your mind? Undo puts everything back.
